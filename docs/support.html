Support

Need help with World Tree? This page explains how to get assistance, report issues, and contact the project maintainers.

Before Requesting Support

Before opening a support request, please ensure you have:

  • Read the project documentation and README.
  • Verified you are using the latest available version.
  • Searched existing GitHub issues for similar reports.
  • Collected any relevant logs or error messages.

General Support

Questions about installation, deployment, configuration, commands, dashboard setup, authentication, or general usage should first be answered by the project documentation. If the issue remains unresolved, please open a GitHub Issue with enough information for the maintainers to reproduce it.

Reporting Bugs

Bug reports should include:

  • Operating system and environment.
  • Node.js version.
  • Steps to reproduce the issue.
  • Expected behaviour.
  • Actual behaviour.
  • Error messages or logs (with secrets removed).

Feature Requests

Suggestions for new features or improvements are welcome. Please describe the problem your idea solves and, if possible, explain how it would benefit server administrators or users.

Security Issues

If you discover a security vulnerability, please do not create a public issue. Instead, follow the responsible disclosure process described in the Security page and the repository's SECURITY.md .

Response Times

World Tree is an actively maintained open-source project. Support is provided on a best-effort basis. Response times may vary depending on project activity, request complexity, and maintainer availability.

Community Guidelines

Please remain respectful when requesting support. Harassment, spam, abusive behaviour, or intentionally misleading reports may result in requests being closed without further action.

Contact

General enquiries can be made through the Contact page. Future releases may also provide a dedicated support email and additional community support channels.

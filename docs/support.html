Support

Support

Support for World Tree is currently handled through the project repository and maintainer-managed channels.

General help

For installation, environment, deployment, or command questions, use the repository documentation first, then open a GitHub issue if the problem is reproducible.

Bug reports

Use the bug report template and include logs with secrets removed, reproduction steps, environment details, and expected behavior.

Sensitive issues

For security problems, follow the process in Security and the repository SECURITY.md instead of opening a public issue.

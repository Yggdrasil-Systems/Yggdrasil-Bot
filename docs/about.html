World Tree

World Tree is a self-hosted Discord moderation, utility, music, and backend platform project built around a single-process Node.js runtime with a growing Fastify API.

What it does

World Tree provides Discord moderation workflows, activity roles, automod, utility commands, music playback, and API foundations for a future authenticated dashboard.

How it runs

The project is designed for low-overhead self-hosting, typically with PM2, MongoDB Atlas, and Discord OAuth2 for future web-facing access.

Project scope

The current release includes the bot runtime, read-oriented guild API routes, encrypted cookie sessions, and Discord OAuth2 identity flow. A browser dashboard frontend is not part of the current release.

About World Tree

World Tree is an open-source Discord platform developed under Yggdrasil Systems, combining moderation, automation, utility, music, and web services into a modern, modular, self-hostable application.

Our Mission

World Tree aims to provide communities with a secure, high-performance, and extensible Discord platform that balances ease of use with powerful administrative capabilities. Rather than being a collection of unrelated commands, the project is designed as a cohesive ecosystem where moderation, automation, authentication, APIs, dashboards, and future services work together through a shared architecture.

Core Features

  • Advanced moderation and administrative tools.
  • Configurable automoderation system.
  • Utility and quality-of-life commands.
  • Music playback with an evolving Lavalink-based architecture.
  • Discord OAuth2 authentication.
  • Encrypted session management.
  • REST API for future dashboard functionality.
  • Low-overhead self-hosted deployment.
  • Open-source development with comprehensive documentation.

Architecture

World Tree is built around a modular Node.js runtime with clear service, repository, and routing boundaries. The project follows a layered architecture designed to improve maintainability, testing, and long-term scalability while avoiding unnecessary complexity.

Current technologies include Fastify, MongoDB Atlas, Discord OAuth2, encrypted cookie sessions, structured logging, and a modular command framework.

Self Hosting

The platform is designed to run efficiently on both personal servers and cloud infrastructure. Typical deployments use PM2 for process management, MongoDB Atlas for persistent storage, and Discord OAuth2 for authenticated web services. The project is intentionally optimized for lightweight, long-running deployments.

Project Status

World Tree is under active development. The current release includes the Discord bot runtime, backend API, authentication system, moderation framework, utility features, and supporting infrastructure. The browser dashboard frontend remains part of the planned roadmap and is not yet included in the public release.

Open Source

World Tree is developed as an open-source project. Documentation, engineering notes, roadmaps, security policies, and contribution guidelines are maintained alongside the source code to encourage transparency and community collaboration.

The Future

World Tree is the flagship project of Yggdrasil Systems. Future development focuses on a full web dashboard, improved music infrastructure, expanded APIs, additional integrations, and reusable packages shared across the wider Yggdrasil ecosystem.

Design Principles

  • Security first.
  • Performance through simplicity.
  • Maintainable architecture.
  • Transparent open-source development.
  • Self-hosting friendly.
  • Developer-focused tooling.
  • Long-term ecosystem growth.

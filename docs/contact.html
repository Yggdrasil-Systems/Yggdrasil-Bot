Contact

Need to get in touch? This page describes the official communication channels for World Tree and the Yggdrasil Systems project.

GitHub Repository

World Tree is developed as an open-source project under Yggdrasil Systems.

Repository:
github.com/Yggdrasil-Systems/Yggdrasil-Bot

General Enquiries

Questions regarding installation, configuration, development, documentation, or project usage should be submitted through the project's GitHub repository using Issues or Discussions (when available).

Bug Reports

If you encounter unexpected behaviour, please submit a GitHub Issue including reproduction steps, environment details, and any relevant logs with sensitive information removed.

Feature Requests

Suggestions for improvements and new functionality are always welcome. Please explain the problem being solved and how your proposal benefits users or server administrators.

Security Contact

Please do not report security vulnerabilities publicly. Follow the responsible disclosure process described in the Security Policy.

Future Contact Channels

As the project grows, additional communication channels may become available, including:

  • support@yggdrasil.systems
  • security@yggdrasil.systems
  • Official Discord support server
  • Project website

Response Times

World Tree is maintained on a best-effort basis. While every request is reviewed, response times may vary depending on project activity, request complexity, and maintainer availability.

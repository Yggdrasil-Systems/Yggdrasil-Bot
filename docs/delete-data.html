Data Deletion

Delete Data

World Tree supports reasonable deletion requests for stored operational data.

What can be deleted

Depending on the request, this can include guild configuration, no-prefix privilege records, or OAuth session state. Moderation records may be retained when needed for legitimate server administration or safety history.

How to request deletion

Open a support request through the project repository and include the guild ID, Discord user ID, and a clear description of the data you want deleted.

What happens next

The maintainer will review the request, confirm scope, and remove data where technically and operationally appropriate.

Data Deletion

Delete Your Data

World Tree supports reasonable requests to remove eligible stored data while balancing user privacy, server safety, and operational requirements.

Who Can Request Deletion

Data deletion requests may be submitted by the affected Discord user or by an authorized administrator for data associated with their Discord server. Additional verification may be requested before any action is taken.

Data Eligible for Deletion

Depending on the request, eligible data may include guild configuration, no-prefix privilege records, API authentication session information, temporary cached data, and other operational records that are no longer required for service functionality.

Data That May Be Retained

Certain information may not be immediately removable, including moderation history, audit records, security logs, abuse prevention records, or data required to maintain server integrity, investigate misuse, or comply with applicable legal obligations.

How to Submit a Request

Submit a request through the project's Support page or official GitHub repository. To help process your request efficiently, include:

  • Your Discord User ID
  • The affected Guild (Server) ID, if applicable
  • A clear description of the data you would like removed
  • Any additional information that may help identify the stored records

Verification Process

To protect user privacy and prevent unauthorized deletion requests, World Tree may request reasonable verification that you own the Discord account or have administrative authority over the affected server.

Processing Requests

Requests are reviewed individually on a best-effort basis. If the requested data is eligible for deletion and can be safely removed without affecting required operational records, it will be deleted within a reasonable period of time.

Important Notes

Once eligible data has been permanently removed, it generally cannot be recovered. Continued use of World Tree after deletion may result in new operational data being created as part of normal service usage.

Questions

If you have questions about data deletion or privacy, please visit the Support or Contact pages.

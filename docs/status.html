Status

World Tree is actively maintained. The current repository state includes the Discord runtime, encrypted auth/session infrastructure, and read-oriented guild API routes.

Current release posture

The bot runtime is production-oriented for self-hosted use. The dashboard frontend remains planned work; only the supporting auth and API foundation are currently implemented.

Operational checks

The API exposes a health endpoint and the project includes a comprehensive Node test suite. Long-running music behavior should continue to be monitored in real deployments.

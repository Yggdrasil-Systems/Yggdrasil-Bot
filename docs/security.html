Security

Security

World Tree uses explicit trust boundaries, encrypted sessions, and strict runtime configuration validation to reduce avoidable risk.

Security posture

The current platform uses Discord OAuth2 with PKCE, signed cookies, AES-256-GCM encrypted session payloads, strict environment validation, and a service/repository architecture designed to keep trust boundaries explicit.

Responsible disclosure

Do not publish sensitive findings in public issues. Follow the policy in the repository SECURITY.md file.

High-sensitivity areas

Authentication, session handling, no-prefix access, moderation permissions, and music external-process execution are treated as high-sensitivity areas during maintenance.

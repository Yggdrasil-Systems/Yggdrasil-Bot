Privacy Policy

This policy explains what World Tree stores, why it stores it, and how data is handled.

Data collected

World Tree stores only the data needed to operate the bot and its supporting API. This can include guild settings, moderation case records, no-prefix privilege records, and encrypted authentication session cookies for the API.

Discord data

When a user interacts with the bot or authenticated API, World Tree may process Discord identifiers, usernames, guild identifiers, moderation reasons, and limited profile data returned by Discord OAuth2.

Music and activity data

Music commands and activity-role features process transient Discord presence, voice, and request data to provide functionality. These features are not used to build advertising profiles or sell data.

Storage

Persistent application data is stored in MongoDB Atlas. API authentication uses encrypted, signed cookies. World Tree does not use localStorage or plaintext OAuth token storage.

Data sharing

World Tree does not sell personal data. Data may be disclosed only when necessary to operate the service or comply with legal obligations.

Retention

Data is retained only as long as needed for moderation history, guild configuration, security, and system operation, unless deletion is requested and the request can be safely honored.

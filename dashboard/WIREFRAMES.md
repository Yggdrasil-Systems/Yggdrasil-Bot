# Dashboard Wireframe Foundation

## Home

Compact overview of connected guilds, bot health, and recent moderation volume.

## Guild Settings

Controls for mod-log channel, trusted admin roles, feature toggles, and
moderation behavior.

## Automod

Rule cards for bad words, mention spam, repeat spam, link spam, and caps spam.
Each card exposes enabled state, thresholds, punishment, and logging status.

## Moderation Cases

Filterable table with case ID, target, action, status, moderator, and created
date. Case detail pages expose resolve and soft-delete actions.

## Command Reference

Readable slash, prefix, and admin shortcut documentation generated from command
metadata in a later phase.

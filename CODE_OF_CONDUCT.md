# Code of Conduct

## Our Standard

This project expects respectful, technically honest collaboration.

Examples of behavior that helps:

- constructive code review
- precise bug reports
- clear reproduction steps
- respectful disagreement focused on the code
- documenting tradeoffs instead of arguing from ego

Examples of unacceptable behavior:

- harassment or personal attacks
- hostile or demeaning language
- sharing private information without permission
- intentionally disruptive behavior
- bad-faith security disclosure

## Enforcement

Project maintainers may remove comments, close discussions, or block participation when behavior harms the project or its contributors.

## Scope

This applies to issues, pull requests, discussions, and other project communication channels.
